# Mandoob+

منصة تربط **الشركات** بـ**مندوبين مستقلين** داخل المدينة: تسجيل، إنشاء مهام، قبول، تتبع حالة،
دفع عند الاستلام بعمولة ثابتة (15 ر.س)، **وتتبع مباشر لموقع المندوب** على لوحة الشركة.

## التشغيل
```bash
node --version        # 22.5 أو أحدث
npm start             # http://localhost:3000
```
لا توجد اعتماديات (لا `npm install`): خادم Node + SQLite المدمجة + واجهة عربية RTL.
متغيرات اختيارية: `PORT`, `HOST`, `DB_FILE` (افتراضيًا `data/mandoob.db`), `SESSION_SECRET`
(وإلا يُولَّد ويُحفظ في `data/.session-secret`). عند النشر خلف HTTPS مرّر `X-Forwarded-Proto: https`
لتفعيل `Secure` على الكوكي.

> مشاركة الموقع في المتصفح تتطلب HTTPS (أو localhost). الخريطة تستخدم Leaflet + OpenStreetMap
> من CDN؛ إن لم تتوفر تظهر لوحة إحداثيات بديلة بنفس التحديث الحي.

## الشاشات
تسجيل/دخول · لوحة الشركة (مقاييس + تتبع حي + أحدث المهام) · مهمة جديدة · قائمة المهام (فلترة للشركة،
قبول فوري للمندوب) · تفاصيل المهمة (مسار الحالات، الدفع، اتصال، تتبع، أزرار البدء/الإتمام) · الحساب.
مع حالات التحميل والخطأ وعدم الاتصال وإعادة المحاولة.

## التتبع المباشر
المندوب (بعد قبول المهمة) يرسل موقعه تلقائيًا عبر `watchPosition` كل ≥4 ثوانٍ (ونبض كل 12 ثانية عند الثبات)
← `POST /api/market/tasks/:id/location` ← الخادم يحفظ آخر موقع + مسارًا ويبثّه عبر SSE لشركة المهمة فقط
← الخريطة تتحرك لحظيًا مع "آخر تحديث" والدقة، وتنبيه إن مرّت 30 ثانية بلا تحديث. احتياط: استطلاع كل 10 ثوانٍ.

## الاختبارات
```bash
npm test                                   # 8 اختبارات API (صلاحيات، سباق القبول، SSE…)
node --no-warnings test/e2e.mjs            # سيناريو كامل بمتصفح حقيقي (يتطلب playwright)
node --no-warnings test/e2e.mjs --leaflet-stub
```
المرجع الكامل للـAPI في `API.md`. ملفاتك الأصلية محفوظة في `legacy-expo-reference/`.

## قواعد العمل
- السعر 50–50,000 ر.س؛ العمولة ثابتة 15 ر.س؛ صافي المندوب = السعر − العمولة.
- القبول ذرّي (مندوب واحد فقط)، ضمن مدينة الشركة، ولا يقبل المندوب مهمة جديدة قبل إنهاء مهمته الحالية.
- الحالات: جديدة → مقبولة → جارية → مكتملة؛ والتحصيل النقدي يُسجَّل عند الإتمام.
- الدفع الإلكتروني (moyasar) محجوز في المخطط فقط وغير مفعّل.
